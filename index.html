ABOUT THIS VISUALIZATION

Four views. One shared selection.

The guiding question is how access and student composition differ across selective college groups. The initial view includes all 139 colleges. The school-group selector also includes Ivy-Plus: the eight Ivy League colleges plus Stanford, MIT, Duke, and the University of Chicago.

Data & methods

The 139-college universe and school-group categories come from Chetty, Deming & Friedman’s college admissions study. The original pipeline estimates remain in the downloadable data; the comparison plots use directly labeled admission rates and student-income shares.

The race and quintile views use supplementary Mobility Report Cards tables joined on super_opeid. These historical cohorts differ: this dashboard supports comparison, not a same-cohort causal analysis. Table 2 substitutes 1983–84 birth cohorts when data for 1980–82 are incomplete.

The map sums revised IPEDS Fall Enrollment 2014 EFRES01 by EFCSTATE: first-time degree/certificate-seeking students’ permanent home states when admitted. IPEDS institutions are joined by their OPEID roots and the published Table 11 college-cluster crosswalk. Every one of the 139 selected colleges has residence data. The default percentage divides enrolled entrants from each home state by the state’s total resident population, multiplied by 100. Population denominators are the Census Bureau’s July 1, 2014 estimates (NST-EST2014-01, 2014 vintage); all ages are included. The national population-weighted percentage is total entrants divided by total population across the 50 states and DC. Other map modes show raw counts or the state’s share of the selected incoming US class. The optional state-entrant rate divides by all IPEDS-reported first-time entrants from that state. These are matriculation counts, not race-specific or state-specific admission probabilities. Race uses the four released 2000 categories, weighted by ipeds_enrollment_2000; the remaining share is labeled “Other / unreported.” Income uses par_q1…par_q5, weighted by count and normalized for rounding.

Some identifiers pool campuses; home-state flows sum matching campus records. The roster’s college-state column uses the largest campus location. Missing values are omitted only from the affected chart, never replaced with zero. Ohio State has no exact income-table match and is excluded from the income calculation. Each chart shows its coverage. Estimates include disclosure protection and are historical.

Design & interactions

A choropleth shows enrolled entrants from each home state as a percentage of the state’s total population, making differently sized states comparable. Horizontal bars make enrollment-category percentages easy to compare on a common baseline. The donut emphasizes the five income shares as parts of a whole; the legend provides exact values. The brushed scatterplot uses x-position for admission rate, y-position for lower-income enrollment share, and categorical color for public versus private colleges. A rectangular brush selects colleges and updates the map, bars, donut, and table. Dots outside the selection remain visible as context.

Alternatives considered: a bubble map would obscure state comparisons and overlapping campuses; a stacked race bar makes small categories harder to compare; a parallel-coordinate plot made overlapping college profiles hard to follow. The single scatterplot focuses on one interpretable relationship and provides the shared selection for the other views. A bar chart would compare income quintiles more precisely, but the requested pie-style view is retained with explicit percentage labels.

  • Dynamic queries: school-group dropdown and college-name search filter all four views.
  • Brushing and linking: drag a rectangle in the scatterplot to select colleges; the map, bars, donut, and table update immediately. Moving or resizing the box updates the selection continuously; clear selection restores all matching colleges.
  • Linked selection: click a map state or use its dropdown to inspect students from that home state and their destination colleges. State inspection changes the map details; the race/income charts retain their national college-level measures because no state-specific breakdown is released.
  • Details on demand: chart hover/focus tooltips; linked dot and table-row highlighting; clicking a dot reveals exact values below the plots.
  • Reset and export: clear filters or download the selected joined data.

Percent axes begin at zero; the home-state map uses an ordered light-to-dark scale. Filters and chart marks support keyboard access. State borders use US Atlas 3. Charts use D3 7 and TopoJSON Client 3; the dashboard code is custom.
